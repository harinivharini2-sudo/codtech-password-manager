# CodTech Internship — Task 1

## Password Manager (Encryption)

**Intern ID:** CITS9489

### Project Description
This is a simple Python password manager that uses the Fernet encryption method to encrypt and decrypt stored passwords.

### Technologies Used
- Python
- Cryptography library
- JSON

### Features
- Save passwords in encrypted form
- Retrieve and decrypt saved passwords
- Store password data locally
- Reuse a saved encryption key

### How to Run
1. Install the required library:
   `py -3.15 -m pip install cryptography`
2. Run the program:
   `py -3.15 password_manager.py`

### Security Note
This is a beginner learning project. Use dummy credentials only; it is not intended for storing real passwords.
